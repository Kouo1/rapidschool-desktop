# rapidschool-desktop

Installeurs de **RapidSchool Desktop** pour Windows.

## Téléchargement

Rendez-vous sur la page officielle de téléchargement : https://rapidschool.cm/telecharger-desktop

Ou téléchargez directement depuis l'onglet **Releases** de ce dépôt.

## Quel fichier choisir ?

- **RapidSchool-Setup-Complet.exe** : première installation sur le serveur de l'école (Windows 10/11, 64 bits). Inclut la base de données PostgreSQL 18 et Java 8.
- **RapidSchool-Setup.exe** : mise à jour, poste relié au serveur de l'école, ou PostgreSQL déjà installé. Sans base de données ni Java (Java 8 ou plus récent requis). Fonctionne en 32 et en 64 bits.
- **RapidSchool-Setup-Complet-32bits.exe** : serveur de l'école sous Windows 32 bits. Inclut PostgreSQL 10 (dernière version publiée en 32 bits, plus maintenue) et Java 8. Préférez un serveur 64 bits dès que possible.
