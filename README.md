# rapidschool-desktop

Installeurs de **RapidSchool Desktop** pour Windows (10/11, 64 bits).

## Téléchargement

Rendez-vous sur la page officielle de téléchargement : https://rapidschool.cm/telecharger-desktop

Ou téléchargez directement depuis l'onglet **Releases** de ce dépôt.

## Quel fichier choisir ?

- **RapidSchool-Setup-Complet.exe** : première installation. Inclut la base de données PostgreSQL.
- **RapidSchool-Setup.exe** : mise à jour, ou PostgreSQL déjà installé. Sans base de données.
